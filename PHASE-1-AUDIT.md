> **Phase 2 implication:** there is no ISR here. Vite has no server runtime and no `revalidate`. The closest equivalents are (a) fetch GitHub at `vite build` time via a plugin/prebuild script that writes a JSON snapshot into the bundle, with redeploys triggered on a schedule (Vercel cron / GitHub Action), or (b) a Vercel Edge/Serverless function with `s-maxage` caching that the client calls. I'll put both options in the Phase 2 proposal.
